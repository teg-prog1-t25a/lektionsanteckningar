# Lektionsanteckningar

Det här repot innehåller den kod som läraren skrivit under lektionen.

Materialet är sorterat efter datum för lektionen och därefter filnamn i nummerordning.

Efter lektionen kan läraren ha kommenterat koden och möjligen gjort små ändringar/rättat fel så att den skall vara lättare att läsa i efterhand.
